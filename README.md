# ❝ QuoteGen - Random Quote Generator

A modern, responsive web application that generates random inspirational quotes. This project demonstrates asynchronous API handling, dynamic DOM manipulation, and modern CSS styling with a "Glassmorphism" aesthetic.

## 🌟 Features

* **Instant Quote Fetching**: Retreives random quotes asynchronously from an external API.
* **Social Sharing**: Integrated Twitter button to instantly tweet the current quote and author.
* **Dark & Light Mode**: Includes a theme toggle that saves the user's preference to Local Storage.
* **Responsive Design**: Fully optimized for Desktop, Tablet, and Mobile devices.
* **Glassmorphism UI**: Features a modern, semi-transparent frosted glass effect.
* **Smart Typography**: Automatically adjusts font sizes for longer quotes to maintain layout integrity.

## 🛠️ Technologies Used

* **HTML5**: Semantic structure.
* **CSS3**: Custom properties (variables), Flexbox, Keyframe animations, and Media Queries.
* **JavaScript (ES6+)**: Async/Await, Fetch API, and DOM manipulation.
* **API**: [DummyJSON Quotes API](https://dummyjson.com/docs/quotes).
* **Icons**: FontAwesome.
* **Fonts**: Google Fonts (Poppins).
