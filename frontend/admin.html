Security Notes

Important information about admin panel security.

  • Admin session is stored in sessionStorage — auto-expires when the browser tab is closed.
  • Admin tokens are separate from user tokens and expire after 4 hours.
  • Password changes are persisted to .env and take effect immediately.
  • This panel is not linked from any public page — keep the URL private.
  • Google OAuth users cannot have their passwords reset (they have no password).
